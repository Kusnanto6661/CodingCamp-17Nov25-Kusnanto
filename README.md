## 💡 Konsep dan Branding

Branding perusahaan fiktif ini didasarkan pada tema **Engineering/Shipwright** yang terinspirasi dari **Franky (Kru Topi Jerami One Piece)**. Keputusan desain ini untuk menekankan nilai **inovasi, rekayasa kode yang kokoh, dan semangat membangun solusi yang "Superrr!"**

## ✨ Fitur Utama yang Sudah Diimplementasi

1.  **Welcome Message:** Menampilkan pesan selamat datang yang dipersonalisasi.
2.  **Validasi Form Kustom:** Implementasi validasi yang ketat menggunakan JavaScript dan Regex.
3.  **Tampilan Hasil Submit:** Menampilkan data *input* form secara *real-time* setelah validasi berhasil.
4.  **Desain Responsif:** Layout diatur agar adaptif di berbagai ukuran layar.
5.  **Struktur Profesional:** Mencakup file `LICENSE` (MIT) dan `README.md`.

## ⚙️ Teknologi yang Digunakan

* HTML5
* CSS3
* JavaScript (ES6+)
