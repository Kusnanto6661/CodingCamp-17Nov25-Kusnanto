## 🌟 Fitur Utama & Highlight Teknis

Ini adalah bagian terpenting. Kami menjelaskan bukan hanya fitur, tetapi **teknologi di baliknya**.

### 1. Operasi CRUD Asynchronous (Simulasi API)
To-Do List pada aplikasi ini tidak menggunakan Local Storage.
* Menggunakan `async/await` dan `Promise` untuk mensimulasikan waktu tunggu jaringan (latency) selama **0.5 detik** pada operasi **GET, POST, dan DELETE**.
* Menunjukkan pemahaman tentang arsitektur **API-First** dan penanganan *Loading State* (`Tombol Menyimpan...`).

### 2. Fetch API Integration
* Mengimplementasikan Fetch API untuk mengambil data dari sumber eksternal (`quote.json`), mendemonstrasikan kemampuan mengambil dan memproses data JSON.

### 3. Client-Side Form Validation
* Validasi formulir kontak yang ketat diterapkan menggunakan **Vanilla JavaScript** untuk memastikan integritas data sebelum pengiriman (simulasi).

### 4. User Experience (UX) Improvement
* Penerapan **Smooth Scrolling** (`scroll-behavior: smooth;`) dan *hover effect* pada item portofolio untuk meningkatkan pengalaman pengguna.
